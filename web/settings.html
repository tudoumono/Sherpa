個人設定

自分にだけ効く設定です。チャットに使う AI・許可されている場合は自分の API キー、 表示の好みを設定します。API キーは画面に再表示しません。 使えるモデルの一覧や機能ごとの AI の割り当ては管理者の「システム管理」で管理します。
この画面の使い方 →
チャットに使う AI（既定）
チャットの回答に使う頭脳の既定です。 チャット画面のメニューからも変更できます（この既定そのものが書き換わります）。
許可されている場合は、自分の API キーを下の「API キー」で設定できます。
API キー（あなた専用）
管理者が許可している場合、現在選ばれているクラウド AI について 自分専用のキーを入力できます。使うモデルは管理者の「使えるモデル」設定に従います。

OpenAI

キーは管理者が設定します（このパソコン・利用者ごとの入力はできません）。

ローカル LLM（Ollama）

管理者が許可した接続先から選びます。使うモデルは管理者の既定に従います。

Codex（チャット専用・自分で資料を探して調べる）

Web 検索はチャット画面のやりたいことブロック（参照する行）で会話ごとに切り替えます。管理者が許可し、頭脳が Codex（OpenAI 直結）のときだけ表示されます。
OpenAI 本家への接続は API キー不要（CLI の `codex login` で認証）。接続先が Azure OpenAI 等の OpenAI 互換エンドポイントのときは、上の「OpenAI」欄の API キーを使います（保存前の入力中の値でも接続テストでは使えます）。モデルは管理者の「使えるモデル」の設定に従い、思考の深さは管理者が決めた基準値（未設定なら `medium`）に従います（どちらも個人設定にはありません）。ナレッジ抽出には非対応（チャット用）。接続テストは通常 CLI の有無とログイン状態を確認しますが、接続先が Azure OpenAI 等のときは実際に1回接続して確認します。
外部連携（自分の API キー）
他のアプリからこの Sherpa の検索・変換を、あなた専用のキーで呼び出せます。 アクセスできる範囲はあなたの権限内に限られます。発行直後だけキー本体を表示します（以後は再表示できません）。
