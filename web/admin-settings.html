AIプロバイダ（クラウド）
クラウドの AI は1つだけ選べます（同時に複数は使いません）。 選んでいない側のキーは消えずに残りますが使われません。ローカル AI（Ollama）は別枠でいつでも併用できます。
クラウドの選択に関わらず、常に使えます（社内のローカル AI・排他選択の対象外）。
OpenAI の接続先
「その他 OpenAI 互換」を選んだ場合、接続先 URL のホストが私有アドレス（10.x/172.16-31.x/192.168.x/ 100.64.0.0-100.127.255.255 等）・localhost・.local/.internal/.lan 等の非公開名・ドット無しの裸のホスト名の いずれかならチャット画面に「社内サーバ」、公開ホスト（例: api.example.com）なら「クラウド（OpenAI 互換）」と 表示されます。この判定は DNS 解決をせず URL 上のホスト表記だけで行うため、私有 IP に解決される公開ホスト名を 設定している場合でも表記どおり「クラウド（OpenAI 互換）」表示になります。
接続先を変えると、検索の索引（埋め込み）が今の設定と合わなくなることがあります。切替後は資料フォルダの再取り込みが必要になる場合があります。
詳細設定
自分のパソコンだけなら空のままで構いません（localhost は常に使えます）。
外部連携キーの Webhook URL は、ここに登録した host:port （またはこのサーバー自身＝localhost）宛てにしか設定できません（誤って社内の 他システムへ通知が飛ぶことを防ぐ・「外部連携（API キー）」タブで宛先を登録）。
調べる深さの基準値
チャットの調べ方ブロックにある「調べる深さ」 （標準・深く・最大）が探索の反復回数やヒット件数などにかける倍率の、標準時の基準値です。 「深く」「最大」はこの値を元に自動で増減します。空欄のままなら組み込みの既定値が使われます。
頭脳が Codex のときだけ効きます。他の AI には推論レベルの指定自体がありません。
チャットの質問例（クイック入力）
チャット画面を開いたときに表示される、クリックで入力欄に読み込める質問例です。 空欄のままなら組み込みの既定（4例）が使われます。

検索1回あたりの情報量（予算）
AI が資料を検索するとき、一度に読み込む情報量の上限です。 広いほど検索の精度が上がりますが、AI への送信量（利用料）も増えます。空欄のままなら 既定値（精度優先・広め）が使われます。単位は KB（1KB=1024バイト）です。
全体の上限に達すると、その時点までに調べた内容だけで回答をまとめます （調べきれなかった旨も併せて伝えます）。
現在のモデルの窓（一度に読める分量の上限）が分かっている場合、上の予算はその窓を 超えないところまで自動的に絞られます（窓が大きくても、上の予算より増えることはありません）。
このモデルの窓が未登録です。既定予算で動作中です——窓のトークン数を下の表に登録すると、 予算が自動調整されるようになります。
モデルの窓の登録（任意）
プロバイダAPIから自動で分からないモデルの窓（トークン数）を 手動で登録できます。行を追加・値を上書き・不要な行を削除できます（プロバイダ名は 「使えるモデル」タブと同じもの・モデル名は実際に使っているモデル名と一致させてください）。

他のアプリ（Dify 等）からこの Sherpa の検索・変換を呼び出すための キーです。発行直後だけキー本体を表示します（以後は再表示できません・控えを保管してください）。 呼び出し回数の上限は「発行後、最初の呼び出しから24時間ごとの枠」で数えます（サーバーの再起動でカウントがリセットされます）。
