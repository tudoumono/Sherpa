## 開き方

- **一覧**: [`index.html`](index.html) — 10項目の番号・名前・見どころ・試し方。

  操作自体は生きたままになります。

### 既存「思考の流れ」アニメとの関係（#5 補足）

右ペインの「思考の流れ」は**すでに本番で SSE 駆動**です（`onNode` が `fstep`/`fnode` を
`active→done` に更新・`app.css` の `.fstep.active`/`glow`/`corepulse`）。今回のデモの再生はこれを
タイマーで模擬しているだけで、本番では**新規実装ではなく既存イベントの活用**になります。
追加コストは主に「回答本文のトークン流し」と「カードの逐次表示」の描画側演出です。
