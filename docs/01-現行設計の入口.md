## Sherpa とは（現在の設計・短く）
社内資料フォルダを登録し、**チャットで**検索・分析・影響範囲調査を行う業務AI基盤。

- **入口はチャット**（タスク起点・専門用語ゼロ・回答末尾に出典＝原本ダウンロード）。画面設計の一次情報は [04-画面の原則.md](04-画面の原則.md)。
- **取り込み＝ディレクトリの鏡**：登録フォルダ＝1つの世界（world）、範囲＝フォルダの階層そのもの、変更は即座に反映（更新=置換／削除=消える）。「版」という概念は持たない。一次情報は [03-鏡モデル.md](03-鏡モデル.md)。
- **エージェント**：Codex(gpt-5.5) を中核に使用。仕様問い合わせ/トラブルシュートは AI が grep・検索・グラフを自律的に調べるエージェント型、影響分析は Neo4j による決定的な探索。
- **スタック**：WSL / FastAPI / Codex CLI / OpenAI・Gemini・Ollama / Elasticsearch / Neo4j / PostgreSQL。
- **認証・共有・個人ワークスペース・Codex の個人書き込み・監査**は実装済み（一次資料は [06-認証と個人領域.md](06-認証と個人領域.md)）。
