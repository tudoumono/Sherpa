# 12. 使い方：ログイン・共有・個人ファイル

このページでは、ログイン後に使える個人機能を説明します。

## ログインする

Sherpa は既定でログイン必須です。各画面を開く前にログイン画面へ移動します。

1. `/ui/login.html` を開く、または未ログイン状態で画面を開いてログイン画面へ移動します。
2. 管理者から発行された**ユーザー名**と**パスワード**を入力します。
3. ログイン後は、元の画面またはチャット画面に戻ります。

画面右上には現在のユーザーが表示されます。ログアウトするときはチャット画面右上のログアウトボタンを使います。

初期管理者は次のアカウントです。

| 項目 | 値 |
|------|----|
| ユーザー名 | `admin` |
| 表示名 | `Administrator` |
| email | `admin@sherpa.local` |
| 初期パスワード | `Sherpa2026!`（`SHERPA_ADMIN_PASSWORD` を設定した場合はその値） |

初期 `admin` は、初回ログイン後に必ずパスワード変更画面へ誘導されます。変更が終わるまで、チャット、管理画面、取り込みなどには進めません。
新しいパスワードは 8 文字以上の半角英数字・記号のみです。全角文字や空白は、見間違いによるログイン不能を防ぐため使えません。

> 開発・検証で認証を無効化する場合だけ `SHERPA_AUTH_DISABLED=1` を設定できます。通常利用では使わないでください。

## 会話を共有する

自分が作成した会話は、招待したユーザーに読み取り専用で共有できます。

1. チャット画面で共有したい会話を開きます。
2. **共有**ボタンを押します。
3. 招待するユーザー名を入力します。複数人はスペースまたはカンマで区切ります。
4. 有効期限を選び、共有リンクを発行します。
5. 表示されたリンクを招待相手へ渡します。

共有リンクは、**ログイン済み**かつ**招待されたユーザー**だけが開けます。共有された会話は会話一覧の「共有された会話」に表示され、読み取り専用になります。

### 共有できない会話

個人ファイルを参照した会話は、そのままでは共有できません。個人ファイル名や内容が他ユーザーへ漏れるのを防ぐためです。共有ボタンは無効になり、共有しようとしても拒否されます。

「個人ファイルを使った会話は共有しない」と覚えておいてください。

## マイワークスペースを使う

**マイワークスペース**は、自分だけが使える個人ファイル置き場です。

- アップロードできるのはテキスト系ファイルです。
- 既定の上限は 10MB です。
- 個人ファイルは自分だけが一覧・検索できます。
- 共有ナレッジの Elasticsearch / Neo4j には入りません。
- 個人ファイルは共有会話の引用元にはなりません。

マイワークスペース画面では、個人ファイルのアップロード、一覧表示、削除、ファイル内検索ができます。

チャット画面の入力欄付近にある**個人ファイルを追加**からも、本人のマイワークスペースへ直接アップロードできます。共有ナレッジには入りません。

## チャットで個人ファイルを参照する

チャット入力欄の近くにある**個人ファイル参照**をオンにすると、自分のマイワークスペース内のファイルも検索対象になります。

回答では、共有ナレッジの出典とは別に **個人ファイル内ヒット** として表示されます。個人ファイルは共有 KB へ索引化されず、他ユーザーの検索結果にも出ません。

個人ファイル参照は既定オフです。社内共有資料だけで調べたいときはオフのまま使います。

アップロード直後にその会話で使いたい場合は、**個人ファイル参照**をオンにします。個人ファイルを参照した会話は共有できません。
