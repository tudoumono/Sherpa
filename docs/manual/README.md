# Sherpa - 製品マニュアル

社内の業務ドキュメント（設計書・仕様・COBOL/JCL/コピーブック・Office 資料など）を対象に、
**「変更の影響範囲」「障害の原因候補」「仕様の問い合わせ」を会話で調べられる**社内向け AI 基盤です。

検索エンジン（全文・グラフ）と AI エージェントを組み合わせる Agentic RAG として、**根拠（出典）つき**で答え、
出典はワンクリックで**原本ファイルをダウンロード**できます。
