# 00. 製品概要

## これは何か

**業務AI基盤**は、社内の業務ドキュメントを対象にした **Agentic RAG**（AI エージェントが自分で資料を調べて答える仕組み）です。
人が大量の設計書やソースを追わなくても、**会話で問いを投げると、根拠つきで答えが返り、根拠の原本をその場で開けます**。

## 何ができるか（4つのやりたいこと）

利用者は依頼内容を会話で書くだけで、システムが適切なやりたいことを選びます。

| やりたいこと | 問いの例 | 返るもの |
|--------|----------|----------|
| **影響範囲分析** | 「消費税率を変えると何に影響する？」 | 影響件数＋対象一覧＋**経路**＋根拠。構造的な影響が無いときは資料からの関連候補（推定）を提示。Excel 出力も可 |
| **トラブルシュート** | 「夜間バッチが異常終了した、原因は？」 | 確度順の**原因候補カード**（なぜ・確認手順・出典） |
| **仕様の問い合わせ** | 「請求額はどう算出している？」 | 該当箇所の抜粋＋出典（無ければ「該当見つからず」と正直に返す） |

ナレッジ参照をオンにした回答は、**根拠があれば末尾に出典**（リンク＝原本DL：Office なら元の Excel/Word、ソースなら原文）を付けます。**根拠が無ければ「確証なし」と明示**します（素の会話＝ナレッジ参照オフでは出典は付きません）。

## 誰のためか

- **利用者**（開発・保守・運用の担当者）: チャットで影響調査・障害調査・仕様確認。
- **管理者**: 対象フォルダの取り込み、ナレッジグラフの確認、全文検索、ユーザー管理、監査ログ確認。
- **運用担当**: サーバ・ストア（DB）の運用。

## 全体像

```
            ┌─────────────────────────── 利用者（ブラウザ） ───────────────────────────┐
            │  ログイン   チャット   マイワークスペース   取り込み/グラフ   管理画面          │
            └───────────────────────────────┬───────────────────────────────────────┘
                                            │ FastAPI（アプリ核：ホスト直）
        ┌───────────────────────────────────┼───────────────────────────────────┐
        │  AI エージェント（OpenAI / Codex / Gemini / Ollama）が道具で自分で調べる        │
        │   道具:  全文 grep（原文）  ・  ES 全文検索（全文・BM25）  ・  グラフ近傍（影響）   │
        └───────────────────────────────────┼───────────────────────────────────┘
                          ┌─────────────────┼─────────────────┐
                     Elasticsearch         Neo4j            原本／派生MD
                    （全文・BM25）      （影響グラフ）     （登録フォルダ＝鏡 / data/derived）
```

- **ログイン後に利用**し、会話・個人ファイル・共有はユーザーに紐付きます（`SHERPA_AUTH_DISABLED=1` の開発・検証時だけ admin 互換）。
- **登録したフォルダがそのまま共有ナレッジになる**（「ディレクトリの鏡」）。フォルダ木が範囲そのもの。
- 検索の経路は依頼に応じて選ばれる: **grep（原文の完全一致）／ES（全文・表記ゆれ/自然文）／グラフ（影響の経路）**。
- AI は外部（OpenAI 等）を使えますが、**ファイルは外部に残さず、本文テキストのみを送る**設計です。
- 個人ファイルは**マイワークスペース**に置き、本人だけが grep できます。共有 KB の全文索引やグラフには入りません。

## スタック

WSL / FastAPI / Codex CLI / OpenAI API / Gemini API / Ollama / Elasticsearch / Neo4j / RDB（PostgreSQL）。
DB（ストア）だけ Docker、**アプリ核（FastAPI・取り込み・解析・AI 実行）はホスト直**で動きます（[40-運用](40-運用.md)）。

## 設計の芯（覚えておくと迷わない3点）

1. **ディレクトリの鏡**: 登録フォルダ＝1つの世界＝1グラフ＋1全文索引。フォルダ木がそのまま範囲。取り込みを実行すると更新は置換・削除は消える（自動ファイル監視ではない）。
2. **根拠主義**: 出典のない断定はしない。根拠があれば末尾に出典（リンク＝**原本DL**）、無ければ「確証なし」と明示。
3. **共有と個人の分離**: 共有ナレッジは全員の根拠、個人 workspace は本人だけの補助情報。個人ファイルを参照した会話は通常共有できません。
