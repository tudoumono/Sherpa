# 23. 管理：文書の重要度

この版では、文書の重要度は**検索・回答・画面に使いません**。登録フォルダに `_重要度.txt` を置いても、
検索の並び順、全文検索の点数、影響調査の一覧、チャットの出典の目印、資料一覧の表示は変わりません。
`_重要度.txt` 自体は、これまでどおり資料としては扱われません（検索や回答の対象になりません）。

## 資料の優先と除外（管理者だけ）

先に読ませたい資料や、検索に出したくない資料は、「資料」画面の「資料の優先と除外」で選びます。

1. 「資料」画面の右上の「資料の優先と除外」を開きます。
2. フォルダかファイルを 1 つずつ選び、設定を「なし」「優先」「除外」から選びます。
3. 「保存する…」を押すと、変えた内容の一覧が出ます。内容を確かめて「保存する」を押すと、次の質問からすぐ効きます。取り込み直しは要りません。

- **優先**: 利用者が選んだ範囲の中で、その資料を先に読み、結果の上の方に出します。「範囲の外でも読む」を付けると、利用者がほかの範囲を選んでいても、その資料を探す対象に足します。この場合、回答の出典に「選んだ範囲の外・管理者が優先にしている資料」と添えます。
- **除外**: 利用者が何を選んでいても、検索に出しません。回答の出典にも出ません。Windows のフォルダ・ファイルは消えません。「なし」に戻せば、すぐまた検索に出ます。
- **親と子**: フォルダに付けた設定は、その下のフォルダ・ファイルすべてに効きます。親に設定を付けると、その下に個別に付けていた設定は、保存のときに消えます（保存の確認で知らせます）。親に付いている間、その下は個別には変えられません。
- 設定は場所（フォルダ名・ファイル名）で覚えます。名前を変えたり移したりしたものは、別の資料として扱われ、設定は付いていきません。Windows 側で消えた場所の設定は、この画面を開いたときに取り除き、「消えた場所の設定を n 件取り除きました」と知らせます。
- 範囲を選ぶ一覧には、除外したフォルダも今までどおり出ます。除外した資料の名前を挙げて質問されたときは、「管理者が検索から外している資料です」と答えます。
