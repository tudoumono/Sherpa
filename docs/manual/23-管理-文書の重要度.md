# 23. 管理：文書の重要度

この機能は管理者向けです。操作には登録フォルダ（資料フォルダ）へのファイル操作権限が必要です。

## 何のための機能か

社内の資料には、正本として扱いたい重要な文書もあれば、下書き・古い版・参考程度の資料もあります。
**「文書の重要度」を登録フォルダの中に置くだけで指定できる**ようにし、検索結果の並び順や
チャットの回答が、重要な文書を優先して使うようにする機能です。

- 検索でヒットが多いとき、**重要度の高い文書が優先して残り**ます。
- 全文検索の並び順にも反映されます。
- 影響調査の一覧も、重要度の高い文書に関わるものが上に来ます。
- チャットの回答の出典に、重要度の目印（バッジ）が付きます。

**この機能を使わなくても構いません**。登録フォルダに何も置かなければ、検索結果・並び順・
スコアは今までとまったく同じです。使うかどうか、どこまで使うかは登録フォルダの管理者が
自由に決められます。

## 付け方

登録フォルダの好きな階層に、`_重要度.txt` という名前のテキストファイルを置きます。
このファイル自体は検索や回答の対象にはなりません（文書として扱われません）。

1行に1つのルールを書きます。書式は次のとおりです。

```
パターン: 高|中|低|なし  # 理由（省略可）
```

例:

```
*: 中
*.cbl: 高  # 基幹バッチの本体
old/*: 低  # 旧版フォルダ
draft_*: なし  # 下書きは対象外に戻す
```

- **パターン**はファイル名・パスの一致条件です（`*` によるワイルドカードが使えます）。
  フォルダ全体に既定値を付けたいだけなら `*: 中` のように1行書けば十分です。
- 値は **高・中・低・なし** のいずれかです。
- `#` の後ろに理由を1行だけ書けます（省略可）。理由は台帳やチャットの出典に表示されることがあります。
- 空行や `#` で始まる行は無視されます（コメント扱い）。
- 同じファイルの中で複数の行が一致する場合は、**後に書かれている行が勝ちます**（上から下へ
  読んで、最後に一致した行が採用されます。パターンの書き方の複雑さでは決まりません）。

## 継承のルール（フォルダをまたぐとき）

`_重要度.txt` は登録フォルダのどの階層にも置けます。ある文書の重要度は、次の順で決まります。

1. その文書がある**フォルダから見て一番近い祖先**のうち、その文書に一致するルールを持つ
   `_重要度.txt` を探します。
2. 一番近い祖先の `_重要度.txt` に一致するルールが無ければ、**さらに上の階層**へ探しに行きます
   （見つかるまで祖先を遡ります）。
3. どの階層にも一致するルールが無ければ、その文書には重要度の情報自体が付きません（未設定のまま）。

**「なし」は特別な意味を持ちます**。祖先が高・中・低のいずれかを指定していても、より近い階層で
`なし` に一致させれば、そこで**完全に中立へ戻し**、それより上の祖先は見に行きません
（「打ち消して終わり」という指定です）。

## 置かなければ何も変わらない

登録フォルダに `_重要度.txt` を一切置いていなければ、検索のヒット・並び順・全文検索のスコア・
影響調査の並び順・チャットの出典表示は、**すべて今までとまったく同じ**です。この機能は
「使いたい人・使いたいフォルダだけ効かせる」設計であり、既存の運用に影響を与えません。

## いつ反映されるか

`_重要度.txt` の追加・変更・削除は、**次回の取り込み（再取り込み、または定期ポーリング）で
即座に反映**されます。旧「版」を残す仕組みはなく、常に今のフォルダの中身がそのまま検索・
分析に使われます（[20. 管理：資料の取り込み](20-管理-取り込み.md)の「ディレクトリの鏡」と
同じ考え方です）。

## 検索・分析への効き方

| 経路 | 効き方 |
|------|--------|
| 資料の直接検索（grep） | ヒット件数が上限に達したとき、**重要度の高い文書ほど優先して結果に残り**ます（同じ重要度なら見つかった順）。ヒットには重要度と理由が付くことがあります。 |
| 全文検索 | 「高」を付けた文書は検索順位が上がりやすく、「低」を付けた文書は下がりやすくなります。「中」や未設定の文書は変わりません。 |
| 影響調査 | 影響一覧の並び順が、重要度の高い文書に関わる項目ほど上に来るようになります。 |
| チャットの回答（出典） | 出典（原本ダウンロードのリンク）に、「高」は目立つ表示、「低」は控えめな表示の目印が付きます。「中」や未設定には何も付きません。 |

## 管理者が構文エラーを確認する

`パターン: 値` の形になっていない行や、値が高・中・低・なし以外の行は、その**行だけ**が
無効になります（ファイル全体が無効になるわけではなく、他の有効な行はそのまま効きます）。

構文エラーがある場合は、「[20. 管理：資料の取り込み](20-管理-取り込み.md)」の取り込み状況一覧に
警告として表示され、どの `_重要度.txt` の何行目に問題があるかを確認できます。また、資料一覧の
各行には付与された重要度が列として表示され、どの `_重要度.txt` のどの行が効いたかも確認できます。
