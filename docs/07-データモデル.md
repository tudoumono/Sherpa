# データモデル（as-built）

> **位置づけ: as-built（現在の実装）** — 現行スキーマ（`sherpa/store.py` の `_SCHEMA`）に対応するデータモデル。
> 取り込み/範囲/同一性の一次情報は [03-鏡モデル.md](03-鏡モデル.md)、認証・共有・監査・個人workspace の as-built は
> [06-認証と個人領域.md](06-認証と個人領域.md)、グラフ語彙は [05-グラフ語彙.md](05-グラフ語彙.md)。矛盾時はこれらの一次情報/実装を優先。
>
> **版モデル時代の設計**（`versions` ライフサイクル・状態遷移図・3層モデル・`kbs`/`analyses`/`usage_events`/`shares` 等）は
> 開発リポジトリ内部の資料に退避している（現行の実装には存在しない）。

RDB（PostgreSQL）が一次情報源。会話・台帳・ユーザー・共有・監査・個人workspace 台帳を保持し、検索実体
（ES チャンク・Neo4j ノード/エッジ）は派生。派生は world 単位で削除/再構築される（鏡モデル・[03-鏡モデル.md](03-鏡モデル.md) §4）。

## KB データモデル（取り込み・範囲・同一性）

### worlds（取込ディレクトリのレジストリ）
鏡モデルの中核。**1 world = 1 参照元フォルダ**（双方向 1:1）。旧 `versions` テーブル（版ライフサイクル）を置換。

| 列 | 型 | 備考 |
|----|----|------|
| kb_id | TEXT, default `global` | 将来の部門スコープ余地（現状 `global` 固定） |
| world_id | TEXT | 取込ディレクトリ識別子（PK は `(kb_id, world_id)`） |
| root_path | TEXT | 参照元のルート（WSL パス・external_reference の鏡元）。`UNIQUE(kb_id, root_path)`＝二重登録禁止 |
| label | TEXT | 表示名 |
| storage_mode | enum(`external_reference`,`managed_copy`) | 既定 `external_reference`（参照元をその場で鏡） |
| last_sig / last_synced_at / last_manifest | TEXT / TIMESTAMPTZ / JSONB | 変更検知の署名・最終同期時刻・最後に取り込んだファイル明細（差分判定の基準） |
| created_at / updated_at | TIMESTAMPTZ | |

> **rebind（参照先変更）＝その world を全削除して新パスから作り直し**（差分でなく破棄→再作成・1 tx atomic・失敗時ロールバックで
> 旧グラフ/台帳/バインドを保持＝fail-closed）。参照元が消失/マウント不可なら **world unavailable**（fixtures/旧KB へ落とさない）。
> 実装＝`sherpa/worlds.py`（registry・rebind）／`sherpa/ingest/world_neo4j.py`（world_id＋scope_prefixes 影響）。

### documents（文書台帳＝doc_ledger）
world 内の各文書を **パス由来の doc_id** で管理する台帳。`sherpa/doc_ledger.py` がコーパス（md/src＋`structure.json`）から seed し、
取り込みワーカー（`sherpa/ingest/worker.py`）が実取り込み時に書く。

| 列 | 型 | 備考 |
|----|----|------|
| id | PK | |
| kb_id | TEXT, default `global` | |
| version | TEXT | world 識別子（コード内部の識別子名は当面 `version`＝利用者非露出。語彙統一はリファクタリング計画フェーズ2） |
| name | TEXT | **doc_id**（MD=stem／ソース=basename・grep/グラフと一致）。`UNIQUE(kb_id, version, name)` |
| layer | enum(`common`,`version`,`personal`) | 範囲の層。`common`＝ルート位置の共通領域 |
| scope_path | TEXT, NULL可 | world 内のフォルダパス（先頭セグメント無し・NULL=直下）。範囲フィルタに使用 |
| doctype | TEXT | 設計書/規約/障害/運用手順/copybook/cobol/jcl/script/config… |
| branch | enum(`source`,`office`) | ソース系（`src/`・MD化しない）か Office/PDF 系（`md/`）か |
| original_path | TEXT | 原本（DL保証）URI。出典→`/documents/download` が原本バイナリを返す基底 |
| md_path | TEXT, NULL可 | MD化版（Office 枝のみ非NULL）。ソース系・personal は NULL |
| status | TEXT | 変換・登録・索引状態 |
| updated_at | TIMESTAMPTZ | |

> **同一性＝パス**（複製は別ノード）。doc_id は `name`（basename/stem）で台帳を引き、DL は `documents.resolve`（パス基準・root 限定）で
> 原本へ解決する（設計書もソースも同じ経路・[05-グラフ語彙.md](05-グラフ語彙.md) §3）。ES/Neo4j の派生物は `world_id`＋原本 rel でキー付けし、
> world 削除/rebind 時に孤児化しないよう自動掃除する（`sherpa/reconcile.py`）。

### ingest_runs（取り込み・抽出のステージング＝グラフ反映境界）
抽出結果を run 単位で記録し、Neo4j へのグラフ反映（確信度ベース・自動）の境界を持つ。

| 列 | 型 | 備考 |
|----|----|------|
| id | PK | |
| kb_id / version | TEXT | 取り込み先 world（`layer=common` の run は version=NULL） |
| layer | enum(`version`,`common`) | |
| ingest_source_id / scan_root / scope_mapping_overrides | INTEGER / TEXT / JSONB | 取込元・スキャンルート（legacy 入口の名残） |
| source_doc_ids | JSONB | 対象 `documents.name[]` |
| status | enum(`extracting`,`auto_published`,`auto_published_with_flags`,`failed`) | 既定は自動グラフ反映。`_with_flags`＝低確信/不一致を `要確認` ラベルで反映（保留しない） |
| extraction_snapshot / published_snapshot | JSONB | 抽出スナップショット／Neo4j 反映内容（差分・再反映の基準） |
| created_by / created_at / published_at / republished_at | | `published_at` は実反映時のみ |

> **(再)実行は world 全体のクリーン rebuild**（当該 world グラフを削除→再構築・削除→ロードを1 write tx で原子化・
> 途中失敗で live グラフを壊さない）。実装＝`sherpa/ingest/worker.py`。

> **ingest_sources（legacy 入口・註）**: `windows_path`/`browser_upload` の取込元登録テーブルは残るが、
> 現行の取り込み入口は **`/worlds` へのフォルダ登録**（`web/ingest.html`＝「資料」画面。旧
> `web/ingest-new.html` は S3-A（2026-07-08）統合後の薄いリダイレクトのみ）。`/ingest/sources` 系は legacy 入口で
> 既定 410、auto-scope 推定/要確認/overrides は撤去（鏡モデルへの移行に伴う整理）。

## 派生ストアとの関係
- **ES**（`sherpa/es_index.py`）: **world 単位インデックス**（kuromoji BM25 ＋任意の dense_vector）。`version`/`scope_path` メタで絞る。
  **共有 KB のみ**（個人workspace は索引化しない）。内容ハッシュで未変更チャンクを再 embed しない。`documents` と原本 rel で接続。
- **Neo4j**（`sherpa/ingest/world_neo4j.py`）: **論理1世界＋フォルダフィルタ**（world ごとの物理 DB 分離はしない）。影響 traversal の Cypher に
  `world_id + scope_prefixes` を入れる。ノード/エッジ語彙は [05-グラフ語彙.md](05-グラフ語彙.md)。
- **個人workspace**（`personal_workspace_files`）: **grep のみ**。ES/Neo4j 取り込み対象に絶対含めない（RAG 非索引の不変条件）。
- **カスケード削除／孤児掃除**: world 削除・rebind・命名変更で派生物が孤児化しないよう、取込/削除/起動の直後に自動掃除
  （`sherpa/reconcile.py`＋`es_index.reconcile`/`world_neo4j.reconcile`）。

## 範囲（scope）の考え方
範囲＝フォルダ木そのまま（[03-鏡モデル.md](03-鏡モデル.md) §3）。`top_scope`（第1セグメント）/`phase`（第2）/`category`（第3）で
グラフも ES も同じ絞り方をする。`layer=common`（ルート位置の共通領域）は選択範囲へ自動合流する（`sherpa/scope.py`）。
版内/工程/活動を**推定しない**（フォルダ木が真＝auto-scope 推定・要確認(scope) は撤去）。`要確認` は「壊れた取り込み」のみ。

## 実装の所在
- registry＝`sherpa/worlds.py`／範囲フィルタ＝`sherpa/scope.py`／台帳 seed＝`sherpa/doc_ledger.py`
- グラフ＝`sherpa/ingest/world_graph.py`（パス同一性グラフ＋L意味層）・`sherpa/ingest/world_neo4j.py`（world_id＋scope_prefixes）
- 取り込みワーカー＝`sherpa/ingest/worker.py`／Office→MD＝`sherpa/ingest/office_md.py`
- スキーマ全文＝`sherpa/store.py` `_SCHEMA`

## 残論点
1. コード内部識別子 `version`/`scope_path` → world 語彙への統一（リファクタリング計画フェーズ2・API 互換受理層つき）。
2. `documents.version` の FK 厳密化・`status` enum 化・kb（部門）スコープの本格導入タイミング。
