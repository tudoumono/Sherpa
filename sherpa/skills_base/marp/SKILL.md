# Marp による日本語スライド作成レシピ（Markdown→スライド）

Sherpa 管理のベーススキル（自作）。**Marp 形式の Markdown を書くだけ**で、テーマが見た目を保証した
スライドが HTML/PDF/PPTX で出力される。座標を手で計算しないので**速く・崩れない**。

**レンダ（HTML/PDF/PPTX への変換）はこのスキルの作業範囲外**。この作業（Codex の実行）が完了した後、
Sherpa 本体がネットワーク隔離下で自動的にレンダする（M3 案2・2026-07-12）。marp CLI を自分で
呼び出す必要は無い。サーバに marp が導入されていない場合は、レンダは行われず `.md` のみが成果物になる
（その場合も `.md` は正しい Marp 形式で書いておくこと）。

## まず使い分けを判断する（重要）

- **見た目重視のスライド／発表資料**（提案・説明・報告のプレゼン）＝**このスキル（Marp）**が既定。
- **あとで PowerPoint（本文・図形・アニメ）で編集したい**と明示された場合は、**このスキルを使わず
  pptx スキル（python-pptx）を使う**。Marp の PPTX は**1スライド＝1枚の画像**で貼られており、
  PowerPoint で**本文テキストの編集はできない**（画像ベース）。

## Marp ソースの front-matter（先頭に必ず置く）

Markdown の先頭に YAML front-matter を置く。型は次の通り（16:9 は既定サイズなので `size` 指定は不要）:

```markdown
---
marp: true
theme: sherpa
paginate: true
---
```

- `marp: true` … このファイルを Marp スライドとして扱う（必須）。
- `theme: sherpa` … 同梱テーマ（Sherpa の柔らかいトーン）。後述の `--theme-set` で読み込む。
- `paginate: true` … 各スライドにページ番号を付ける。

## レンダは Sherpa 側が自動で行う（このスキルではコマンドを実行しない）

このスキルの作業は `.md` を書くところまで。Codex の実行が完了すると、Sherpa 本体が
ネットワーク隔離（unshare）下で marp CLI を実行し、同じディレクトリに `.html` / `.pdf` / `.pptx` を
自動生成する（`--theme-set` で同梱テーマを読み込み・`--no-stdin` 等の実行時フラグも Sherpa 側で付与
する）。サーバに marp が導入されていない場合はレンダされず、`.md` のみが成果物になる
（正しい front-matter で書いておけば後日レンダできる）。

- 日本語フォントは `'Noto Sans CJK JP', 'IPAGothic', sans-serif` でフォールバック描画される
  （テーマ側で指定済み・文字化けしない）。

## 成果物として残すもの（複数ファイル）

- **Marp ソース `.md` も成果物として残す**（削除しない）。後から「3枚目を直して」に応えるための再編集元。
- レンダ結果（`.pptx` / `.pdf` / `.html`）が生成されれば `.md` と**両方**がカレントディレクトリ
  （authoring 直下）に残る。
- 生成ファイルは Sherpa 側の生成ファイルカードにそのまま列挙される（複数ファイル可）。

## 共通ルール（このスキル固有・AGENTS.md の全体ルールと併用）

- 成果物は**カレントディレクトリ（authoring 直下）**に保存する。サブフォルダは作らない。
- ファイル名は内容が分かる日本語＋拡張子（例: `消費税率変更_説明資料.md` / `.pptx`）。
  OS で問題になる文字（`/ \ : * ? " < > |`）は使わない。
- ネットワークアクセス（画像 DL・外部フォント取得等）は不可。ローカルの情報だけで完結させる。
- 作成が終わったら、**作った `.md` のファイル名**と**内容の要約（2〜4文）**を回答の最後に日本語で
  報告する（レンダ結果はこの作業の完了後に生成されるため、この時点ではまだ存在しない）。

## Marp 記法の型

各スライドは `---`（水平線）で区切る。front-matter の閉じ `---` の後、最初のスライドが始まる。

```markdown
---
marp: true
theme: sherpa
paginate: true
---

# 消費税率変更 説明資料

調査結果のご報告

---

## 影響範囲

- **BILLINGJOB（確実）** … 税額計算ロジックを直接参照
- **TAXCALC（要確認）** … 関連コピーブック経由

---

## 対象一覧

| 区分 | 対象 | 判定 |
|------|------|------|
| Module | BILLINGJOB | 確実 |
| Module | TAXCALC | 要確認 |
```

- 見出し `#`＝タイトル、`##`＝スライド見出し。箇条書き `-`、表 `| … |`、**強調**、`インラインコード` が使える。
- **1スライドに詰め込みすぎない**（箇条書きは目安5〜7行まで・表は1画面に収まる行数）。
  情報が多い場合はスライドを分ける（`---` を足す）。

## 出典・根拠

- 出典・根拠を含める場合は、ユーザから渡された事実（doc_id・引用等）を**そのまま転記**する。
  推測で埋めない（事実に無いことは書かない）。
