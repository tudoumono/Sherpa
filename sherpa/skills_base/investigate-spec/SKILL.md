# 仕様・記載内容の問い合わせレシピ

Sherpa 管理のベーススキル（自作）。型は「まずツールで当たりを付け→読取ツールで原本の中身を確かめて
→答える」。**rag.md や検索結果の抜粋だけで断定しない**——最終確認は必ず読取ツールで原本を開いて行う
（検索結果は当たりを付けるための手掛かりに過ぎない・Python を書くのは読取ツールで終わらない定型外の
ときだけ）。

## 1. 最初に開くもの（当たりの付け方）

1. 固有名詞・型番・関数名など具体語がある場合は `ripgrep_search(query=...)` で全文 grep する（完全一致に強い）。
2. 言い回しが揺れる概念・自然文の問い合わせは `es_search(query=...)`（0件/空振りのときも試す）。
3. どちらもヒットが弱いときは `doc_outline(doc_id=...)` で見出し構造を見て、該当しそうな章・シートの
   当たりを付けてから読む箇所を絞る。
4. ヒットした `doc_id` の周辺だけでよいときは `read_around(doc_id=..., line=..., window=...)`、
   通読が要るときは `read_doc(doc_id=..., start_line=...)`。`text_truncated` が付いたら続きを読む。

## 2. 中身の確認（読取ツールが第一）

検索・精読で当たりが付いたら、**まず読取ツールで原本を直接読んで**該当箇所を引用する（Python は
書かない）。開くときは必ず読取専用（読取ツールはそもそも書き込まない）。

### Excel（.xlsx）

`xlsx_sheets(doc_id=...)` でシート名・行数・列数を確認してから、`xlsx_range(doc_id=..., sheet="Sheet1",
range="B3:D10")` で該当セル範囲を表で読む（`range` 省略時は先頭200行×50列）。返った `rows` の中から
キーワードに該当するセルを探す。引用するときは「Sheet1!B3:D10」のようにシート名とセル範囲で示す。

### Word（.docx）

`docx_paragraphs(doc_id=..., start=0, count=200)` で段落（`i`・`style`・`text`）と表（`tables`・
先頭20表・各50行）を読む。返った `paragraphs`/`tables` の中からキーワードに該当する段落・行を探す
（表の値は `paragraphs` に含まれない＝`tables` も必ず見る。一致したセルだけでなく同じ行の全セルと
1行目＝列見出しを合わせて見る）。`total` が `start+count` を超えるときは `start` を進めて続きを読む。
引用するときは段落番号（`i`）と見出し（`style` が Heading 系ならその名）、表なら表番号（`i`）・行を示す。

### PowerPoint（.pptx）

`pptx_slides(doc_id=..., pages="1-10")` でスライドのテキスト（`texts`）・表（`tables`）・ノート
（`notes`）を読む（1回20枚まで・`pages` は `"3"`／`"2-5"`／`"1,3,5"` で指定）。引用するときは
スライド番号（`no`）と、表なら行を示す。

### PDF

`pdf_pages(doc_id=..., pages="1-5")` でページのテキスト（`text`）を読む（1回10ページまで）。
返った `text` の中からキーワードに該当する箇所を探す。引用するときはページ番号（`no`）で示す。

### テキスト・コード

`read_doc(doc_id=..., start_line=...)`（通読）／`read_around(doc_id=..., line=..., window=...)`
（周辺精読）で読む。ごく短い先頭だけの確認なら `file_head(doc_id=...)` でもよい。

### 定型外のとき（読取ツールでは終わらない場合）

複数シート・多数ページを横断してキーワードの全出現箇所を集計する等、読取ツールを何度も呼ぶより
Python で一括して開いたほうが速い場合だけ、原本を直接開く（読取専用モードを必ず使う）。

```python
from openpyxl import load_workbook

wb = load_workbook(path, read_only=True, data_only=True)   # data_only=True で数式でなく計算結果の値を読む
for name in wb.sheetnames:
    ws = wb[name]
    for row in ws.iter_rows(values_only=True):
        if any(v is not None and "対象キーワード" in str(v) for v in row):
            print(name, row)
```

大きなファイルは、行数・シート数・ページ数を先に確認してから該当範囲だけを読む（全体を一度に読み込まない）。

## 3. 全件・すべてを求める質問（対象を網羅する場合）

「該当箇所を1つ示す」特定の値の質問とは完了条件が違う。**本文中の項目（機能・帳票・処理・設定値等）を
すべて**求められたら、対象の母集団を確定してから順に確認する（検索ヒットは候補の発見にしか使わない・
検索上位だけを母集団にしない）。

1. 対象資料を `list_docs`／`folder_tree` で確定し、資料ごとにシート数（`xlsx_sheets`）・段落総数
   （`docx_paragraphs` の `total`）・スライド総数（`pptx_slides` の `total`）・ページ総数
   （`pdf_pages` の `total`）を先に把握する。
2. 把握した範囲を順に読む。`truncated`／`text_truncated`／`file_truncated` が付く、または `total` が
   `start+count` を超えるときは続きを読む（読まずに打ち切らない）。続きを取得する手段が無い打ち切り
   （`file_truncated`・pdf_pages の `text_truncated`・glob_search／doc_outline の `truncated`・folder_tree の `folders_truncated`・xlsx_sheets／ripgrep_search／es_search の `truncated`＝ヒット数上限）は、その範囲を
   未確認として明示する（4. へ）。
3. 項目の同一性（同じ項目か）と出典位置（どのシート/段落/ページか）を保ったまま重複を整理する。
   件数の一致だけで、欠落と重複が相殺された状態を合格にしない。
4. 読めない・読み切れない範囲が残る場合は、その範囲を明示したうえで全件性を主張しない（§4）。

## 4. 完了条件と中断

- **特定の値を確かめる質問**: 該当箇所を原本から直接引用でき、根拠の場所（シート名/セル範囲・段落番号・
  ページ番号・行番号）を示せたら終える。
- 複数の候補箇所が見つかった場合は、全て確認してから代表的な根拠を選ぶ（1件目で即断しない）。
- 3回検索しても該当箇所が見つからないときは、**探した範囲を書いたうえで**「資料に記載が見当たらない」
  と答える（無理に近い値で埋めない・未探索の範囲が残るのに断定しない）。
- **全件・すべてを求める質問**は §3 の手順で対象範囲の確認を終え、該当項目が回答にそろったときだけ
  終える。検索3回・根拠1件・件数だけの取得・代表例の発見では終えない。
- **中断**（利用者停止・通信エラー・既存の反復／情報量予算への到達）のときは、確認済みの結果・
  未確認の範囲・中断理由を分けて書き、部分結果を「全件」「すべて」「該当なし」と断定しない。

## 5. 回答の形

- 引用した値・記述は原本の該当箇所（シート名・セル範囲／段落番号／ページ番号）を添えて示す。
- 取得済みの対象項目は要約・代表例化で落とさない。表を指定されたら指定列を守り、項目と行・値の対応を
  保つ。取得できなかった値は推測で埋めず「未取得」と書く。
- 確定した事実（原本に明記された値）と推定（複数箇所から読み取れるが明記はない等）は分けて書き、
  推定には「推定」と明示する。
- 本文の中に出典の一覧は書かない（根拠の箇所＝パス・シート名・セル範囲・段落・ページは本文で示してよい）。
  回答の最後に『参照した資料:』の行を置き、実際に開いて根拠にした資料を1行1件、資料フォルダからの
  相対パスで列挙する。派生MD／rag.mdを見た場合も原本のパスで書く。
